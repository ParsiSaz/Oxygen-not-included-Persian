# Changelog & Version History

All notable changes to the **Oxygen Not Included Persian Localization Project** are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), adhering to [Semantic Versioning](https://semver.org/).

---

## [v1.2.0] - 2026-10-04

### Changed
- Refactored repository structure to conform with the **ParsiSaz 2026 Localization Standard (L10N-STD-2026)**.
- Established `loc/fa-IR/` for decoupled Gettext PO/MO string catalogs.
- Organized `game_assets/strings/` for instant game mod directory extraction.
- Standardized `README.md` with installation guides and links to the [ParsiSaz Documentation Portal](https://parsisaz.github.io/parsisaz/).

---

## [v1.1.0] - 2023-08-15

### Added
- Expanded translations for Spaced Out DLC asteroid biomes and colony management.
- Compiled binary `strings.mo` for faster string lookups in Klei's engine.

---

## [v1.0.0] - 2022-04-10

### Initial Release
- Initial Persian PO localization catalog for base game Oxygen Not Included.
